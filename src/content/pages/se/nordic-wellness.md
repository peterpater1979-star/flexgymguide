Nordic Wellness är en svensk gymkedja med över 400 klubbar, från norr till söder. Du tränar på gym och kan boka gruppträning.

<h2 id="kort">Kort sagt</h2>

| | Nordic Wellness |
| --- | --- |
| **Typ** | Gymkedja med gruppträning |
| **Klubbar** | Över 400 i Sverige |
| **Pris** | Från 299 kr i månaden |
| **Bindningstid** | Beror på medlemskapet; se Nordic Wellness |
| **Gruppträning** | <span class="ja" aria-hidden="true">✓</span> Ja |
